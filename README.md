## ✿ About

**ryu-deco** is a creative playground for developers who want their GitHub profiles to feel more personal.

Create your own tiny characters, decorate cozy environments, add playful animations, and bring everything to life inside your GitHub README.

From snowy winter nights to blooming spring gardens, your profile becomes your very own pixel world.

## ✧ Features (Planned)

**Pixel Art Editor**
- Draw pixel characters on a customizable grid
- Choose colors, brushes, and erasers
- Create your own pixel-art assets
- Save and edit your creations

**World Decoration**
- Customize backgrounds and landscapes
- Add trees, flowers, houses, and decorations
- Choose seasonal themes
- Arrange characters and objects using layers

**Animation Studio**
- Create frame-by-frame animations
- Make characters walk, jump, and sleep
- Add falling snow, sparkling stars, and moving clouds
- Preview your animated world

**GitHub README Integration**
- Export animated pixel worlds as GIFs
- Generate ready-to-use Markdown
- Customize banner dimensions
- Showcase your creation on your GitHub profile
